FF NEXUS HUB + MAX SHOP — FINAL INTEGRATED BUILD

After unzipping, open the FF_NEXUS_HUB folder. Everything needed for the project is inside.

PUBLIC FLOW
Nexus Hub -> Top Up Centre -> MAX SHOP introduction -> Open MAX SHOP -> MAX SHOP
The public MAX SHOP is embedded directly into the Nexus Hub page. It does not navigate to
/max-shop/ and does not depend on a separate MAX SHOP URL.

ADMIN
MAX SHOP admin is separate from Nexus Hub admin. It is not linked from the public site and
is intended to control MAX SHOP only. Set MAXSHOP_ADMIN_PASSWORD in Railway.
