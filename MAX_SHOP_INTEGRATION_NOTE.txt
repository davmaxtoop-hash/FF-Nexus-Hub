MAX SHOP INTEGRATION

Public flow:
FF Nexus Hub -> Top Up Centre -> Open MAX SHOP -> MAX SHOP opens inside the same Nexus Hub page.

The public Top Up Centre card is intentionally minimal: only the heading and Open MAX SHOP button.

MAX SHOP admin is separate and is not linked from the public site.
Admin path is controlled by MAXSHOP_ADMIN_PATH (default: secure-portal-7k4m) and requires MAXSHOP_ADMIN_PASSWORD.

Do not create max-shop/index.html. Keep the main Nexus Hub index.html at the project root.
